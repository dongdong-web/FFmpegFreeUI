# 轻压：本地视频压缩

这是 FFmpegFreeUI fork 中的小白入口，当前版本 0.5.1，面向 Windows 10/11 x64。
简易界面使用标准 WinForms，真实复用上游的预设模型、编码器数据库、质量控制、滤镜组合与阶段化命令生成源码。
这些源码单独编译为无界面的处理库，不加载上游的 LakeUI、Agent、社区、更新器、插件或远程调用。

## 使用

解压完整体验包，双击 `LocalCompress.exe`。不用安装 .NET，不用配置 PATH，不用登录。

1. 添加视频，或把视频拖到窗口。
2. 选择“日常视频”（默认）或“录屏／课程”。
3. 点击开始压缩。默认在原视频旁另存，也可选择本机保存文件夹。

结束统计分别显示已压缩、已跳过和失败。选择任务后，下方结果区直接显示是否生成文件、原始／输出大小、减少比例及完整保存路径，文字可复制。
画质保护、没有变小或已符合上限均显示“未生成文件”，不显示虚构的压缩率。只有选中实际生成且仍存在的文件时，才启用“播放结果”和“定位文件”；定位会在资源管理器中选中该文件。

界面没有编码器、质量值、速度预设、分辨率、降噪或音量参数。
场景适用于本批所有待处理视频；混合素材可分批处理，不声称自动识别内容。
两类场景默认保持尺寸、比例和帧时间，不降噪、不调音量，不为凑压缩率降低分辨率或丢帧。
日常视频优先保持一般实拍观感；录屏／课程使用更保守的质量值，保护小字和图表。
内部继续使用 x264 slow，日常基线 CRF 20、录屏基线 CRF 18。无大小限制且时长至少 8 秒时，自动在开头、中间和末尾各取 2 秒试压，比较基线与日常 CRF 21／录屏 CRF 20 候选。
日常候选需每处 SSIM ≥ 0.985、相对基线下降 ≤ 0.0015；录屏需全帧及四个分区的最差 SSIM ≥ 0.995、每个对应区域相对基线下降 ≤ 0.001。
候选在每处至少节省 2% 视频字节，合计至少节省 10%，才用于整段编码；候选不达标且基线指标合格时采用原场景基线。短视频及大小限制模式不进行这组试压。
若基线本身在任一取样位置低于上述最低指标，则保留原文件，显示“试压提示画质风险”，不生成整段结果。无法测量且没有已知画质风险时回到旧基线策略，不误称通过画质检查。
这些阈值是明确的筛选启发式，不是视觉无损认证。三个位置不能覆盖所有复杂画面，录屏分区也不能保证每个字符。整段仍检查大小和完整性，但不逐帧做画质验收。
试压需要额外 CPU 时间；测量或试压编码不可用时保守回到基线，取消则立即停止并清理属于本任务的样本文件。
这是一组有测试依据的有限策略，不宣称所有素材的最优答案，也不自动切换到 H.265/AV1。
已有首个 AAC 音轨在无大小限制时直接复制；其他音频转换为 192 kb/s AAC。转换仍可能引入损失，不调整响度。
原视频不会覆盖，已有结果不会覆盖；结果没有变小会丢弃临时输出，显示“无需压缩”，保留原件。

“接收方有大小限制”默认关闭，只在用户确实需要上传上限时开启并输入 MB。
1 MB = 1,000,000 字节，批量时对每个视频分别应用，不是整批合计。
该模式复用上游两遍编码命令，音轨按 128 kb/s AAC 预算重新编码。
超限时自动降低码率校正一次，只保存不超限且通过完整性检查的结果。
仍不达标或目标过小时提示增大目标；不会自动降分辨率、丢帧、裁剪或静音。
原视频已符合上限时直接跳过，不生成重复文件。大小约束会影响画质，不能同时承诺任意目标大小和画质不变。

## 隐私范围

- 简易入口没有网络客户端、账号、遥测、AI、自动下载、自动更新或远程服务。
- 只接受本机磁盘文件。网址、UNC 路径、网络映射磁盘、符号链接、目录联接和云占位文件被拒绝。
- FFmpeg/ffprobe 仅允许 `file,pipe` 协议，本地播放列表不能间接获取 HTTP 视频。
- 输入、输出和任务详情均留在本机，任务列表仅保存在进程内存中。
- 输出不复制可选文件元数据或章节；视频画面、声音本身并不会被匿名化。
- .NET 单文件运行时可能在系统临时目录解压运行库；视频临时结果及试压样本写入用户选择的输出目录。
- 应用不上传文件。操作系统、第三方安全软件和云盘客户端是独立程序；需要纯离线存储时，请选择非云同步的本机文件夹。
- 这些约束只覆盖 `LocalCompress.exe`，不覆盖仓库保留的上游专业版程序或自行替换的第三方可执行文件。

## 能力边界

输出 H.264/AAC MP4，默认保持尺寸（奇数边长最多缩小 1 像素），保留第一个视频流和第一个音轨。
字幕、额外音轨、章节和附件不保留。HDR 暂不处理，明确报错并保留原文件。
场景压缩不承诺固定百分比或目标大小。大小限制模式检查上限，两种模式均不承诺视觉无损。采用 CPU 编码，批量任务串行执行。
正常退出和取消会清理试压样本、临时结果及两遍编码统计文件；断电或强制结束进程可能留下 `.localcompress-*` 文件，不会覆盖原文件。

## 开发和验证

需要 .NET 10 SDK；核心、界面和测试没有第三方 NuGet 依赖。

```powershell
dotnet build LocalCompress/App/LocalCompress.App.csproj -c Release
dotnet run --project LocalCompress/Tests/LocalCompress.Tests.csproj -c Release
```

集成测试需要可信的 `ffmpeg.exe` 和 `ffprobe.exe` 在 PATH，包含 libx264、AAC、scale、hqdn3d 和 loudnorm。
测试使用合成视频，覆盖原文件完整性、名称冲突、中文路径、无音轨、HDR、失败、取消、远程播放列表拒绝、横竖屏缩放、降噪与音量组合，以及目标大小、已达标跳过、无效目标、预算不足与两遍编码取消清理。

```powershell
dotnet run --project LocalCompress/UiSmoke/LocalCompress.UiSmoke.csproj -c Release -- artifacts/ui-preview.png
```

原生窗口检查场景默认值、大小限制开关、已移除的参数控件并生成界面预览。该检查不能替代人工端到端体验。

打包（只在开发时准备引擎，用户运行时不下载）：

```powershell
./LocalCompress/package.ps1 -FFmpegDirectory 'D:\tools\ffmpeg-build'
```

引擎目录必须包含 `bin/ffmpeg.exe`、`bin/ffprobe.exe`、`LICENSE` 和 `README.txt`。
产物位于 `artifacts/LocalCompress-win-x64`，包含自带运行时的应用、引擎、许可和使用说明。
发布给公众前须提供所选 FFmpeg 构建及其依赖的对应源代码，按其 GPL 等许可完成分发材料；本次只生成本地体验包，没有公开发布二进制 Release。

## 维护

主程序：`App/MainForm.cs`；本地处理与验证：`Core/CompressionEngine.cs`；测试：`Tests/Program.cs`。
上游基线：`65aec1ff4dcd62a54c4361fe1719520378750c36`。
`Upstream/LocalCompress.Upstream.vbproj` 通过源码链接编译仓库中的原始 VB 预设模块，避免复制后形成两套实现。
`LOCALCOMPRESS_HEADLESS` 条件编译只排除 UI、磁盘设置读取与专业版启动逻辑；编码参数、滤镜图、排序、流映射仍由上游源码生成。
七个纯辅助函数从原有 UI 文件移到 `预设通用函数_v6.vb`，由专业版和简易版共享，函数体保持原样。
`Upstream/PresetCompiler.vb` 将场景和大小限制转换为上游预设，在执行前强制本地协议、禁止覆盖以及清除流元数据。
不接受任意预设 JSON、自定义命令、额外输入或脚本引擎，防止专业扩展能力越过本地压缩边界。
复用的是预设处理层及两遍编码命令，任务执行、批量队列、取消、目标预算与输出验证仍使用简易版实现；硬件加速、字幕烧录、HDR 转换等没有在界面开放。
上游 MIT 声明保留；FFmpeg 与 .NET 运行时使用各自许可。本入口不依赖 LakeUI。

## 画质验证

本地实拍与录屏的 H.264/H.265/AV1 对照方法、结果和局限见 [编码策略试验](CODEC-STUDY.md)。该实验没有改变当前产品默认编码，不需要用户安装 Python。

```powershell
dotnet run --project LocalCompress/QualityChecks/LocalCompress.QualityChecks.csproj -c Release -- artifacts artifacts/quality-report.md
```

默认生成移动图形、渐变细线和录屏小字素材，与旧版均衡设置比较 SSIM、大小和编码时间。
录屏指标仅统计文字附近区域，防止空白区域掩盖文字损失。这是回归测试，不是“肉眼无损”认证。
可对本地短片段进行真实试压（不会修改输入，输出保留在片段旁）：

```powershell
dotnet run --project LocalCompress/QualityChecks/LocalCompress.QualityChecks.csproj -c Release -- artifacts artifacts/real-quality-report.md --daily 'D:\samples\camera.mp4' --screen 'D:\samples\screen.mp4'
```

真实素材模式检查尺寸、时长、输入 SHA256 和 SSIM；仍需在实际观看设备上做动态观感对比。
真实素材报告包含三处试压指标和内部选择结果，帮助开发者检查筛选实际运行；产品界面不显示编码参数。
测试报告和用户素材只留在本地 artifacts 目录，不提交到 Git。
底层保留早期质量/滤镜 API 供兼容与回归测试，场景 API 禁止组合缩放、降噪和响度调整；产品界面仅调用场景 API。
