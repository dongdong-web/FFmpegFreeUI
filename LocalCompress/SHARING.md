# 轻压：分享与分发说明

## 用户下载什么

用户只需下载轻压-0.6.2-win-x64.zip，全部解压后双击 LocalCompress.exe。当前不是单独一个 exe 可运行的结构：主程序自带 .NET 运行时，但仍依赖同目录 tools/ffmpeg.exe 与 tools/ffprobe.exe。

请保留完整运行包，包括 tools、licenses、sources、先读我.txt、使用说明、项目关系声明及校验文件。用户无需另下载 .NET、Python、FFmpeg 或专业版 FFmpegFreeUI，也无需安装源码。

## 夸克网盘目录建议

同一个分享目录放：

- 轻压-0.6.2-win-x64.zip：普通用户下载此完整运行包，已包含内核对应源码。
- 轻压-0.6.2-项目源码.zip：配套轻压项目源码与上游 MIT 声明，供查阅和构建。
- 分享说明.txt：下载与使用方法，项目独立关系。
- 校验SHA256.txt：上述文件的校验值。

运行包中 sources/FFmpeg-x264-corresponding-source.zip 包含 FFmpeg 8.1、固定提交 x264 和 dav1d 的完整源码归档、构建脚本、归档哈希、构建配置、工具链版本及对应二进制哈希。普通用户可以不用打开它；分享时保留，勿拆掉源码和许可证后再分发。

## 与旧版的区别

0.6.2 改用本项目直接从源码构建的内核，外部编解码库只有 x264 与 AV1 解码库 dav1d，其余解码、AAC 编码、容器和滤镜使用 FFmpeg 自带实现。源码包不下载素材，不使视频处理需要联网。内核网络协议关闭。

这份源码材料只对应 0.6.2 的新内核，不能为 0.6.1 及更早的 Gyan.dev 二进制填补对应源码缺口。请分享新版本整包，不混入旧版 tools。许可证、构建参数与具体版本见 licenses 和内核源码包；不承诺任意视频都能大幅缩小或视觉无损。

不要上传开发用 artifacts 整个目录：其中含本地用户视频、试压副本、截图与测试报告。不要把旧版 ZIP、bin/obj、.git、测试素材或电脑路径报告混在用户下载目录。
