# 轻压：分享与分发说明

## 用户下载什么

用户只需下载一个完整运行包 ZIP，全部解压后双击 LocalCompress.exe。当前不是单独一个 exe 可运行的结构：主程序自带 .NET 运行时，但仍依赖同目录 tools/ffmpeg.exe 与 tools/ffprobe.exe。

应保留主程序、tools、licenses、先读我.txt、使用说明、项目关系声明及校验文件。用户无需另下载 .NET、Python、FFmpeg 或专业版 FFmpegFreeUI。源码包不用于日常运行。

不要上传开发用 artifacts 整个目录：其中含本地用户视频、试压副本、截图与测试报告。不要把旧版 ZIP、bin/obj、.git、测试素材或电脑路径报告混在用户下载目录。

## 夸克网盘目录建议

同一个分享目录放：

- 轻压-0.6.1-win-x64.zip：完整运行包，普通用户下载此文件。
- 轻压-0.6.1-项目源码.zip：对应项目源码与原许可证，供查阅和构建。
- 分享说明.txt：下载与使用方法，项目独立关系。
- 校验SHA256.txt：以上文件的校验值。
- 引擎对应源码与构建材料：匹配运行包中的 FFmpeg、静态依赖版本及构建所需材料，公开分发前补齐。

## 当前准备状态

运行包和本项目源码可以在本机生成并验证。当前使用 Gyan.dev 的 FFmpeg 8.1 full GPLv3 构建。构建 README 给出了 FFmpeg 提交 9047fa1b08、依赖版本与构建配置，但没有在本项目内提供完整匹配的静态依赖源码、补丁及构建脚本。原有许可证和几个上游链接不等于对应源码材料已经完整。

因此当前运行包是技术上可运行的本地体验包，尚不能标记为“公开分发材料已齐备”。公开网盘分享前须核齐上述引擎材料，并使下载者可获得与二进制对应的源码；不要只上传应用二进制和项目源码后宣称已经完成全部分发准备。

依据：[FFmpeg 许可说明](https://ffmpeg.org/legal.html)、[构建提供方说明](https://www.gyan.dev/ffmpeg/builds/)。该准备清单记录已知材料缺口，不代替完整法律审查。

不需要用户安装源码，补齐源码也不意味着压缩需要联网。轻压本身依旧在本地运行。
