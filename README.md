# 轻压 · 本地视频压缩

FFmpegFreeUI 的小白用户版。选择视频、按需设置大小上限、开始处理。
视频始终由本机 CPU 处理，原文件保留，结果另存。

## 不需要理解编码参数

- 默认恢复早期均衡方案，无需选择场景或调整编码参数。
- 可选“接收方有大小限制”：输入每个视频的 MB 上限，自动两遍编码；已达标直接跳过。
- 默认保持尺寸和帧时间，不降噪、不调整响度；音频转为 128 kb/s AAC。
- 默认直接均衡编码，不再因保守试压指标而跳过。
- 支持拖入视频、批量处理、实时进度和停止。
- 输出通用 MP4，显示压缩后大小和减少比例。
- 不覆盖原文件或已有结果；结果没有变小则显示“无需压缩”，丢弃临时输出。
- 完整体验包自带 .NET 运行时、FFmpeg 和 ffprobe，解压后运行 LocalCompress.exe。

## 文件全程留在本地

简易入口没有账号、上传、遥测、AI、联网更新或服务器功能。
只接受本机磁盘文件，FFmpeg/ffprobe 限制为本地协议。
若保存位置属于云盘同步目录，云盘客户端可能自行同步，请选择非云同步文件夹。
仓库中的上游专业版是独立程序，这些约束只适用于本分支的 LocalCompress.exe。

## 当前状态

版本 0.5.3，Windows 10/11 x64，已在本机通过真实编码集成测试。
暂不支持 HDR；只保留首个视频流和首个音轨，不保留字幕或额外音轨。
均衡方案的压缩比例由素材决定。目标大小模式只保存不超过上限的结果，不承诺无损或恰好等于目标大小。指标测试不能代替动态观感验收。

当前提供源码和本地体验包，尚未公开发布二进制 Release。

## 与上游的关系

Fork 自 [Lake1059/FFmpegFreeUI](https://github.com/Lake1059/FFmpegFreeUI)，保留上游源码和 MIT 声明。
小白入口位于 LocalCompress/，采用标准 WinForms，源码链接复用上游的预设模型、编码器数据库、质量控制和滤镜命令生成，最终调用本地 FFmpeg。
上游处理逻辑独立编译，无需加载其专业界面或联网功能；任务执行和输出保护仍由简易版负责。
本项目不是上游官方产品。
